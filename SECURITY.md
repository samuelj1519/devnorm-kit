# Security reports

Report suspected vulnerabilities privately through this repository's GitHub **Security → Report a vulnerability** when available. If private reporting is unavailable, contact the owner through the contact information on [their GitHub profile](https://github.com/samuelj1519); omit exploit details from public issues until a private channel is established.

Include the release or commit, affected resource, prerequisites, expected and actual behavior, and a minimal reproduction using fictional data. Never include credentials or private project contents.

Only the current accepted delivery is maintained here. Third-party resources retain their own licenses and recorded origins. Package hashes detect drift; they do not establish trust in a different publisher. Skills retain the invoking task's permissions and do not authorize account changes, deployment, or external writes.
