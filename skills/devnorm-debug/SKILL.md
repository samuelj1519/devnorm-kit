# devnorm-debug

Reproduce before diagnosing; replay the original failure without treating substitute or environment results as success.

Read the target project's current rules and exact task inputs. Preserve its scope, existing authorization, cumulative budget, and required verification. Use [the method](references/methods/debugging/METHOD.md) for this capability. Read related resources only when needed.

For authorized Git actions, task-branch commits use [exact-index quick checks](references/standard/6-version-control/6.3-staging-and-commits.md); integration targets require [trusted full checks](references/standard/3-workflow/3.8-integration-and-completion.md). For user reports, handover, and completion, read that shared section for communication and evidence retention.
