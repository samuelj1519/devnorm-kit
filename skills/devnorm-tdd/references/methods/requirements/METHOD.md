# Requirements and specification

Read the current goal, project facts, and accepted decisions. Clarify unresolved choices or consolidate an agreed specification. Do not interview an already clear small task again.

## Clarify

1. Resolve facts from code, project records, and available primary sources. Ask the responsible owner only for preferences, authorization, or consequential choices you cannot establish.
2. Order questions by real decision dependencies. Limit them to choices that change current scope, acceptance, or design. Give a recommendation, reason, and main trade-off. Continue independent work while awaiting answers.
3. Update the authoritative plan with scope, observable behavior, exclusions, acceptance, unresolved choices, and evidence. A recommendation remains a proposal until accepted. Reuse existing approval.
4. Stop when the current task can be implemented and verified. Keep unrelated ideas optional. At the budget limit, preserve resolved decisions and the next unresolved choice.

## Consolidate

When discussion is settled, summarize existing decisions and acceptance without adding choices or repeating interviews. Reuse authoritative project documents and task briefs. Scale detail to the task; no fixed story count. Mark consequential gaps unresolved. A specification does not replace modeling, independent review, or implementation.

## Explicit request: decision interview

Run a round-based interview only when the prompt explicitly asks for a deep interview, grill-me, or requirements stress test. Establish topic and round/time budget. Follow dependencies that affect the current goal; summarize resolved and remaining choices each round. Do not add a universal confirmation step. Stop at implementable scope or the budget limit.

## Completion and return

Scope, behavior, acceptance, and key decisions support the next stage, or blocking choices are explicit. Keep unresolved semantics in requirements/design. Do not publish tickets, labels, commits, or assignments automatically.

## Source and adaptation

Adapted from pinned Matt Pocock grilling and to-spec. Keeps fact/decision separation, dependency order, and consolidation. Uses bounded clarification and authoritative local records instead of exhaustive interviews or automatic tracker publication.
