# UI copy

For the current user task, check whether each text explains an object, state, action, or recovery.

- Name actions and targets. Keep one name per behavior and avoid repeated title/body/button text.
- Distinguish no data, not yet created, no permission, no filter matches, and load failure.
- Explain errors, effects, and recovery. Preserve error meaning without inventing retry intervals, status codes, or success guarantees.
- Explain the target, consequence, and reversibility of dangerous actions. Match confirmation to actual behavior.
- Use natural language and established project/industry terms. Preserve code, fields, paths, commands, and fixed literals.

Check length, wrapping, accessible names, and state changes in the real layout. Proofreading-only work preserves structure and facts. Record unresolved product meaning first. Chinese copy uses the bundled Chinese-writing method.
