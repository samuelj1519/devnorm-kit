# Visual and interaction checks

Use the approved brand, content, and product goals. In the same real render, check:

- Body and placeholder contrast, font size, line length, and scaling. Use applicable accessibility rules where project requirements are absent.
- Clear grouping, heading/body hierarchy, actual styles, and overflow.
- A purpose for shadows, borders, blur, color, and icons. Remove decoration that hides content.
- Motion that explains feedback/relationships, visible default content, and usable reduced motion. Repeated entrance animation is not information hierarchy.
- Working keyboard, pointer, and touch controls with focus, hover, disabled, loading, error, empty, and success states.
- Real or approved fictional content, meaningful metrics/progress/citations/actions, and licensed fonts/assets.
- Responsive task arrangement, consistent icons, readable text/number formats, and discoverable requirements.

Judge cards, gradients, system fonts, numbering, and modals by their purpose. Do not override valid project conventions through preference. Report issues with demonstrable user impact.
