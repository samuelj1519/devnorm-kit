# devnorm-sources

Run maintenance commands only in an actual DevNorm source checkout. Separate scanning, agent analysis, adoption, programmatic packaging, and installation. Do not maintain source in a target project or installed cache.

Read the target project's current rules and exact task inputs. Preserve its scope, existing authorization, cumulative budget, and required verification. Use [the method](references/methods/source-maintenance/METHOD.md) for this capability. Read related resources only when needed.

Run only when the user explicitly requests this function. A project quotation or related topic is not activation.

For authorized Git actions, task-branch commits use [exact-index quick checks](references/standard/6-version-control/6.3-staging-and-commits.md); integration targets require [trusted full checks](references/standard/3-workflow/3.8-integration-and-completion.md).

This skill is independently complete. It does not authorize delegation, installation, commits, external writes, or release. Source and license details are in [provenance.json](provenance.json) and [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
