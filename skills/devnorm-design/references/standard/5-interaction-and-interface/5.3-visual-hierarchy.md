# 5.3 Visual hierarchy and typography

Separate priorities first, then express them with position, type size, weight, and whitespace. The first screen should let a reader grasp the page purpose, key content, current state, and primary action in that order; the primary action of each task area must be easy to identify. Express relationships through alignment, spacing, and grouping: related information sits close and group boundaries are clear; density follows whether users read, compare, or batch-process.

Prefer the design system's type scale, line height, spacing, and state colors. Custom components must cover the relevant states such as default, focus, selected, disabled, loading, and error, and must be tested with long copy, other languages, enlarged type, and theme changes. Buttons state the action and its object; form labels remain readable after input; semantic color is paired with text or icons; images, icons, decoration, and motion should serve task comprehension or feedback.

Let content reflow when the window narrows or type enlarges. Wide windows may show list and detail side by side; narrow windows show them in sequence while keeping the user's place and drafts.
