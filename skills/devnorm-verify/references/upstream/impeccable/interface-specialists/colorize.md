# Color and contrast

Use only when this concern applies to the UI task. Define semantic color roles for surfaces, text, emphasis, status, and interaction before tuning lightness/saturation. Check light/dark and error/disabled states. Never rely on color alone. Reuse tokens and avoid expanding theme scope for a local effect.

Verify actual visibility and interaction states in the target host. Static styles or DOM presence do not establish visibility. Keep the existing UI acceptance requirements and task scope.
