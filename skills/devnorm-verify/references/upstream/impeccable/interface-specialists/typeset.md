# Typography and content hierarchy

Use only when this concern applies to the UI task. Choose hierarchy, line length, spacing, alignment, and density for the reading task. Reuse project fonts/styles. Check long headings, mixed languages, numbers, zoom, and truncation. Make grouping clear without substituting extra borders or decoration for hierarchy.

Verify actual visibility and interaction states in the target host. Static styles or DOM presence do not establish visibility. Keep the existing UI acceptance requirements and task scope.
