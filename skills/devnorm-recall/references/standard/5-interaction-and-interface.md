# 5. Interaction and interface

Read this chapter when a task involves user interaction or an interface. It applies to web, mobile, desktop, and terminal products, including internal tools, and covers requirement design, prototype review, and delivery acceptance. "Must" marks a delivery requirement when the item applies; "should" marks a design default that may change with evidence. Projects select applicable items by users, task risk, and platform constraints; stricter project requirements still apply, and exceptions follow section 2.1.

Sections 5.1 through 5.7 state product requirements. For acceptance, record applicability, results, and evidence for the section 5.8 checklist in the [task brief](../../assets/templates/task.md). Cases and references are in section 5.9.
