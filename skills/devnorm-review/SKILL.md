# devnorm-review

One non-author primary reviewer starts in a fresh session, then continues incremental reviews and replays original failures. Fix the semantic unit or final combination, base, exact inputs, and cumulative budget. Personally run critical paths. Replace the reviewer after implementation edits; this entry grants no editing or merge authority.

Read the target project's current rules and exact task inputs. Preserve its scope, existing authorization, cumulative budget, and required verification. Use [the method](references/standard/3-workflow/3.6-independent-review.md) for this capability. Read related resources only when needed.

Use [quick checks](references/standard/6-version-control/6.3-staging-and-commits.md) for task-branch commits and [trusted full checks](references/standard/3-workflow/integration.md) for integration targets. For handoff use [evidence retention](references/standard/3-workflow/evidence-retention.md); for reports use [reporting](references/standard/3-workflow/reporting.md).
